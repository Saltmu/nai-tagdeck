# nai-tagdeck

NovelAI の画像生成用プロンプトを、タグの ON/OFF で組み立てる個人用ツール。対象モデルは NovelAI Diffusion V5。

- タグをカテゴリ別に並べ、チェックボックスで ON/OFF（OFF のタグも残る）
- 編集画面の各タグは「編集」で変更できる。保存は作業中のプロンプトにだけ反映し、候補を選んだ元の辞書には反映しない（Enterで保存、Escapeでキャンセル）
- カテゴリの開閉状態をベース・各キャラクター別にブラウザへ保存し、再読み込み後も復元する
- PCの右ペインの「生成」エリアは見出しで開閉でき、状態も保存する。スマホでは常に表示する
- プロンプト全体／カテゴリ単位でコピー（ON のタグだけを `, ` で連結）
- 辞書からの前方一致サジェスト（英語タグ・日本語名・よみ。カタカナ/ひらがな・全角/半角を区別しない）
- 編集画面の空のタグ入力欄にフォーカスすると、そのカテゴリの登録済みタグをすべて候補表示する
- 重みは数値（-3〜3）で持ち、出力時に `1.2::tag::` または `{tag}` / `[tag]` に変換。
  マイナス（`-1::hat::`、V4.5 以降）で要素を取り除ける
- キャラクタープロンプト（最大15人を保存、同時に生成対象としてチェックできるのは6人）。キャラごとに被写体・外見・衣装・着衣状態・ポーズのタグを持ち、
  ON/OFF・並べ替え・個別コピーができる。ヘッダーのコピーはベースのプロンプトだけ
- 公式UIからプロンプトを貼り付けると、カンマ区切り・重み・括弧を読み取ってタグにする
- 辞書の登録・編集・削除、JSON/CSV の一括入出力
- データ（辞書・作業中のタグ）はブラウザの IndexedDB にだけ保存する。サーバーには何も送らない
- NovelAI Diffusion V5 で直接生成（ブラウザから `image.novelai.net` へ。中継サーバーなし）
  - 生成画面で「アニメ」「ケモノ」を選択できる。ケモノでは送信時にベースプロンプト先頭へ `fur dataset` を追加する。選択は再読み込み・バックアップでも保持する
  - サイズ・ステップは Anlas を消費しない範囲（1024×1024 相当以下・28 steps 以下・1 枚）に限定
  - 生成画像は Blob URL でメモリにだけ置き、タブを閉じると消える。画像があるときは閉じる前に確認を出す
  - 拡大表示・保存（PNG）・削除・「このシードを使う」
- プリセット: 作業中のタグ一式（ベース＋キャラクター）に名前を付けて保存・読み込み・上書き・名前変更・削除
- 重みは −/＋ ボタン（0.05 刻み）か直接入力。カテゴリごとの「並べ替え」でタグの順番を変えられる
- バックアップ（設定タブ）: 辞書・プリセット・作業中のタグ・設定を1つの JSON に書き出し／読み込み。端末やサイトの移行用（トークンは含まない）
- Dangerゾーン（設定タブ）: 確認後、辞書・プリセット・作業中のタグとキャラクター・全設定・トークン・開閉状態・生成画像を削除し、初期状態へ戻す
- PWA: ホーム画面に追加でき、一度開けばオフラインでも編集画面を使える（生成には通信が必要）
- トークンは画面から入力し、このタブだけ（sessionStorage）かこのブラウザ（localStorage）に保存する

## 開発

```bash
npm install
npm run dev        # 開発サーバー
npm test           # ユニットテスト（vitest）
npm run build      # 型チェック + dist/ に出力
```

## 配置

`npm run build` で出来た `dist/` の中身を、レンタルサーバーの任意のディレクトリにアップロードする
（相対パスで出力しているのでサブディレクトリでも動く）。`.htaccess` 以外に必要なファイルはすべて `dist/` に入っている。

- PWA（ホーム画面に追加・オフライン）は HTTPS のときだけ有効になる。Service Worker（`sw.js`）は更新が
  すぐ反映されるよう、ページ本体は毎回サーバーから取り、取れないときだけキャッシュを使う。
- アイコンを作り直すときは `node scripts/make-icons.mjs`（`public/icons/` に出力）。

- サイト全体を HTTPS + Basic 認証にする。設定例は [`deploy/htaccess.example`](deploy/htaccess.example)。
- 本番ビルドの `index.html` には CSP（外部スクリプト禁止、通信先は自サイトと `image.novelai.net` のみ）が入る。

## 辞書ファイルの形式

JSON（書き出し形式）:

```json
{ "app": "nai-tagdeck", "version": 1, "entries": [
  { "id": "…", "tag": "blonde hair", "category": "appearance", "alias": "金髪 きんぱつ",
    "default_weight": 1, "sort_order": 0, "updated_at": "2026-10-05T00:00:00.000Z" }
] }
```

`entries` だけの配列も読める。CSV は 1 行目が見出し（`tag` と `category` は必須、他は省略可）。
`category` はキーでも表示名でもよい。

| キー | 表示名 |
| --- | --- |
| `quality` | 品質 |
| `style` | 画風 |
| `subject` | 被写体・人数・関係性 |
| `appearance` | 外見 |
| `outfit` | 衣装 |
| `dress_state` | 着衣状態 |
| `pose` | ポーズ |
| `effect` | エフェクト |
| `composition` | 構図 |
| `background` | 背景・場所 |
| `weather` | 時間・天候 |

読み込み時は「追加・上書き」（同じカテゴリ＋タグは上書き）か「すべて置き換え」を選ぶ。

辞書画面の「初期カテゴリを復元」で、不足する初期タグを追加できる。「外見」には `lean muscular`、`muscular` などの体型タグも含む。同名タグは大文字小文字・全角半角・アンダースコアの違いを吸収してマージし、既存のカテゴリ・日本語名・重み・並び順を保持する。独自に追加したタグも残る。
「背景・場所」と「時間・天候」はベース側の独立したカテゴリ。初期辞書では背景タグを「背景・場所」、雨・雪を「時間・天候」に分類する。登録済みタグは復元時も既存のカテゴリを保持するため、移したい場合は辞書の「編集」からカテゴリを変更する。
端末間で辞書を共有するときは、JSON を書き出して別の端末で読み込む。
