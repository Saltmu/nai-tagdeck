# nai-tagdeck

NovelAI Diffusion V5 向けのプロンプトを、タグの ON/OFF で組み立てる非公式 Web アプリです。作成したプロンプトをコピーして NovelAI で使うことも、アプリ内から画像を直接生成することもできます。

- **[ブラウザで nai-tagdeck を開く](https://shishio.x0.to/nai-tagdeck/)**
- **[操作チュートリアルを試す](https://shishio.x0.to/nai-tagdeck/tutorial/)**

## 主な機能

- **タグ編集とマルチキャラクター**: ベース・キャラクター・ネガティブに分けてタグを管理し、ON/OFF・重み調整・並べ替えができます。キャラクターは最大 15 人まで保存でき、最大 6 人を同時に出力・生成へ含められます。2D キャンバスや 5×5 グリッドでの位置指定にも対応しています。
- **日本語検索できる辞書とプリセット**: よく使うタグに日本語名やよみ、既定の重みを付けて登録でき、JSON / CSV で入出力できます。プロンプト一式をプリセットとして保存したり、NovelAI からコピーしたプロンプトを取り込んだりできます。
- **アプリ内画像生成**: NovelAI の Persistent API Token を設定すると、ブラウザから直接画像を生成できます。精密参照（V5）、インペイント、生成画像の比較、PNG / ZIP 保存、Anlas 残高・消費目安の確認に対応しています。
- **ブラウザ完結・PWA**: データはブラウザ内に自動保存されます。ホーム画面への追加やオフラインでのプロンプト編集に対応しています。

各機能の詳しい操作方法や辞書ファイルの仕様は [操作ガイド](docs/guide.md) を参照してください。初めて使う場合は [操作チュートリアル](https://shishio.x0.to/nai-tagdeck/tutorial/) で実際の操作を体験できます。

## はじめかた

### 1. 初回案内で始め方を選ぶ

初回起動時に、以下の 3 つから開始方法を選べます（後から「設定」→「初回案内をもう一度表示」で選び直せます）。

- **タグの例と辞書を読み込む** — ベースとキャラクター 1 人分の例から試せます。
- **タグ辞書だけ読み込む** — 日本語で検索できる辞書を使い、プロンプトは自分で組み立てます。
- **何も読み込まずに始める** — 自分のタグや辞書だけで始めます。

### 2. 「編集」でタグを組み立てる

| 編集対象 | 入れる内容 |
| --- | --- |
| ベース | 人数（`2girls` など）、画風、構図、背景など、画像全体に共通するタグ |
| キャラクター | キャラクターごとの種類（`girl` など）、外見、衣装、ポーズ、配置位置。タブ右端の「＋」で追加 |
| ネガティブ | 画像全体の Undesired Content（初期値は公式 UI の「heavy」相当）。全キャラクター共通のネガティブも編集可能 |

チェックを外したタグは編集画面に残したまま出力から外せます。重み調整、検索・絞り込み、並べ替え、プロンプト取り込みなどの詳細は [操作ガイド](docs/guide.md) を参照してください。

### 3. プロンプトをコピーするか、画像を生成する

- **NovelAI に貼り付ける場合**: 生成画面下部の「プロンプト」からベース・ネガティブ・キャラクターごとにコピーします。編集画面でもカテゴリ単位やキャラクター単位でコピーできます。
- **アプリ内で生成する場合**: NovelAI のアカウント設定で「Get Persistent API Token」を発行し、「設定」→「NovelAI のトークン」に保存したうえで、画面下部の「生成」から実行します。

## データの保存とプライバシー

| データ | 保存先・移行方法 |
| --- | --- |
| 辞書・プリセット・作業中のタグ・設定 | ブラウザ（IndexedDB 等）に自動保存。「設定」の「バックアップを書き出す」で別端末へ移せる JSON を作成 |
| NovelAI のトークン | 設定時に選んだ「このタブだけ」または「このブラウザに保存」に保持。バックアップの対象外のため移行先では再設定 |
| 生成画像 | タブのメモリに一時保存。再読み込みやタブを閉じる前に PNG または ZIP でダウンロード（ピン留めもタブを閉じると消去） |

- 画像生成や残高取得では、プロンプト・生成設定・トークンをブラウザから `image.novelai.net` へ直接送信します。
- バックアップを読み込むと、辞書とプリセットは追加・上書きされ、作業中のタグと設定はファイルの内容に置き換わります。
- 「設定」の「Dangerゾーン」から、このブラウザの保存データ・トークン・生成画像をまとめて削除できます。
- 一度読み込んだアプリはオフラインでもプロンプトを編集できます（画像生成には通信が必要です）。

## ローカル開発

前提: Node.js 24 系（24.15.0 以上）と npm。リポジトリのルートで以下を実行します。

```bash
npm ci
npm run dev
```

起動後、ターミナルに表示された URL をブラウザで開きます。

| コマンド | 用途 |
| --- | --- |
| `npm test` | Vitest でテストを実行 |
| `npm run lint` | Biome で静的チェックを実行 |
| `npm run typecheck` | TypeScript の型チェック |
| `npm run build` | 型チェック後、公開用の静的ファイルを `dist/` に出力 |
| `npm run preview` | ビルド後の `dist/` をローカルで確認 |
