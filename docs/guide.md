## タグ編集

### タグの追加と取り込み

- **カテゴリ横断で追加**: ベース・キャラクターでは、上部の入力欄でカテゴリを横断して辞書の候補を探せます。カテゴリを指定して追加する場合は、そのカテゴリの入力欄を使います。
- **プロンプトの取り込み**: NovelAI などからコピーしたプロンプトを貼り付けて「追加」を押すと、カンマ区切りや重みの記法を読み取ってタグに分解します。

### タグ一覧の絞り込みと調整

- **検索・絞り込み**: 一覧見出しの虫眼鏡アイコンから追加済みタグを検索できます。「表示」メニューから ON のタグだけに絞ったり、カテゴリをまとめて開閉したりできます。
- **ON / OFF と編集**: チェックを外したタグは、編集画面に残したまま出力・生成から外せます。タグ名は鉛筆アイコンから編集でき、変更は編集中のプロンプトに反映されます。
- **重みと並び順**: 重みは −3〜3 の範囲で直接入力するか、−／＋ で 0.05 ずつ調整します。「並べ替え」でカテゴリ内の順序を変更できます。

### キャラクター管理と位置指定

- **保存と出力の上限**: キャラクターは最大 15 人まで保存できます。タブのチェックで、同時に最大 6 人を出力・生成に含められます。
- **位置指定**: 各キャラクターの配置座標（0〜1）を、2D キャンバス上のクリック／ドラッグ（または矢印キー）や、公式 UI 相当の 5×5 グリッド（A1〜E5）で指定できます。他の ON キャラクターの位置も同時に表示されるため、配置バランスを確認しながら調整できます。

## プロンプトの出力

出力は ON のタグをカンマ区切りで並べた文字列です。

- **強調の記法**: 数値式（`1.2::tag::`）と括弧式（`{tag}`、`[tag]`）を切り替えられます。
- **0 以下の重み**: 0 以下の重みは常に数値式になり、`-1::hat::` のように負の重みを使うと要素を取り除く指定になります。
- **コピー単位**: 生成画面下部の「プロンプト」からベース・ネガティブ・キャラクターごとにコピーできます。編集画面ではカテゴリ単位やキャラクター単位でのコピーも可能です。

## アプリ内での画像生成

### トークンの設定と Anlas 確認

1. NovelAI のアカウント設定で「Get Persistent API Token」を使ってトークンを発行します。
2. nai-tagdeck の「設定」→「NovelAI のトークン」に貼り付けて保存します。保存先は「このタブだけ」か「このブラウザに保存」を選べます。
3. トークンを設定すると、ヘッダーに Anlas 残高が表示され、クリックで手動更新できます。

### 生成設定と制限

画面下部の「生成」でモード・サイズ・ステップ・スケール・サンプラー・ノイズスケジュール・シードなどを確認し、「生成」を押します。

- **モード**: 「アニメ」「ケモノ」を切り替えられます。「ケモノ」モードでは送信時にベースプロンプトの先頭へ `fur dataset` が付きます。
- **サイズ**: 縦・横・正方形・縦長・横長のプリセットに加え、各辺 64〜2048 px・64 の倍数かつ総画素数 1024×1024 相当（1,048,576 px）以下のカスタムサイズを指定できます。
- **ステップ数と生成枚数**: ステップ数は 1〜50 の範囲で指定できます（28 を超えると Opus プランでも Anlas を消費します）。生成は 1 回につき 1 枚です。

## 精密参照とインペイント

### 精密参照（V5）

- 参照画像は最大 6 枚まで登録でき、1 枚ごとに種別（キャラクター／スタイル／衣装）、強さ（0.1〜5.0）、有効／無効（ON / OFF）を切り替えられます。
- 無効化すれば画像を保持したまま通常生成へ一時的に切り替えられます。有効な参照画像に応じた Anlas の消費目安も表示されます。

### インペイント

- 画像に対してブラシ・消しゴム・移動／ズームを使ってマスクを描き、指定した領域を部分的に再生成できます。
- 生成履歴の画像やローカル画像ファイルからインペイントを開始でき、マスク編集の取り消し／やり直しにも対応しています。

## 生成履歴と画像比較

- **拡大表示と保存**: 画像一覧から画像を拡大表示し、PNG を 1 枚ずつダウンロードできます。ピン留めした画像は「ピン留めを ZIP 保存」でまとめてダウンロードできます。拡大表示から、その画像のシードを次の生成に設定したり、プロンプトを取り込んだりできます。
- **画像比較**: 2 枚の生成画像を並べて比較、または切り替え比較でき、プロンプトのタグ差分や重みの変更差分を一覧で確認できます。
- **履歴上限時の自動削除**: 履歴の上限を超えると、新しく生成した画像を残し、既存の画像からピン留めしていない画像を先に、同じ条件ではダウンロード操作済み・古い画像から削除します（すべてピン留め済みのときは、ピン留め画像から同じ順で削除します）。

## 辞書とプリセット

- **辞書**: 再利用したいタグを登録します。日本語名やよみ、既定の重みを設定でき、JSON / CSV で入出力できます。「初期カテゴリを復元」は、不足する初期タグを補いつつ、登録済みタグのカテゴリ・日本語名・重み・並び順を維持します。
- **プリセット**: ベース・ネガティブ・キャラクターのタグ一式をまとめて保存します。プリセット欄の「…」から「新しいプリセットとして保存」で名前を付け、読み込み後は同じメニューの「変更を上書き」で更新できます。ネガティブ対応前の旧プリセットを読み込む場合は、現在のネガティブを引き継ぎます。

## 辞書ファイルの形式

JSON は `entries` を持つオブジェクトか、タグの配列を読み込めます。

```json
{
  "app": "nai-tagdeck",
  "version": 1,
  "entries": [
    { "tag": "blonde hair", "category": "appearance", "alias": "金髪 きんぱつ" }
  ]
}
```

CSV は 1 行目に列名を指定します。どちらの形式も必須項目は `tag` と `category` です。任意項目は `id`、`alias`、`default_weight`、`sort_order`、`updated_at` です。

```csv
tag,category,alias
blonde hair,appearance,金髪 きんぱつ
```

`category` には以下のキーまたは表示名を指定できます。旧形式の `dress_state`（着衣状態）は、読み込み時に「衣装」（`outfit`）に統合されます。

| キー | 表示名 |
| --- | --- |
| `quality` | 品質 |
| `style` | 画風 |
| `subject` | 被写体・人数・関係性 |
| `appearance` | 外見 |
| `outfit` | 衣装 |
| `pose` | ポーズ |
| `effect` | エフェクト |
| `composition` | 構図 |
| `background` | 背景・場所 |
| `weather` | 時間・天候 |
| `negative` | ネガティブ |

辞書の「追加・上書き」は、ID またはカテゴリとタグの組み合わせが一致する項目を更新します。「すべて置き換え」は、読み込んだ内容で辞書全体を置き換えます。初期タグを復元するときは、タグの大文字・小文字、全角・半角、アンダースコアなどの表記差を吸収して同名タグを照合します。
